# Mami Momos Jaipur — A5 Pamphlet Print Specification

## Production Objective

Create handout-ready pamphlets that can be distributed near Hawa Mahal and make the café feel worth the short walk to Gangori Bazaar. The printed object must communicate one offer, a clear momo cue, the café identity, and an easy-to-scan location/redeem instruction within a few seconds.

## Master Format

| Specification | Decision |
| --- | --- |
| Finished size | A5 portrait — 148 × 210 mm |
| Use case | Single-sheet handout, counter insert, or half-A4 print run |
| Bleed target | 3 mm on each edge |
| Content-safe margin | 8 mm minimum from trim line |
| Main headline size | 26–38 pt equivalent at print size |
| Minimum body size | 8.5 pt equivalent at print size |
| Print strategy | Strong dark/light contrast; avoid thin pale copy and full-page low-contrast imagery |
| Master CTA | “Bring this flyer and get 10% off.” |

> **Important:** The offer is an editable placeholder selected from the user’s brief. Confirm the final discount, qualifying spend, validity dates, and outlet-specific terms before sending any file to print.

## Location Copy

**Near Hawa Mahal. A short walk to hot momos.**

`Shop No. 146, Gangori Bazar Rd, Gangori Bazaar, Tripolia Bazar, Pink City, Jaipur 302002`

## Five Design Variations

### 01 — Heatwave

The strongest distribution design. A coral front, near-black typography, a close food crop, a giant 10% stamp, and the address in a dark footer strip. Use when the goal is maximum street visibility.

### 02 — Bazaar Receipt

A light paper field with bold maroon type, receipt-like rules, barcode-style dividers, and a stamped “valid at Gangori Bazaar” callout. Use when the flyer should feel collectible and clearly coupon-driven.

### 03 — Steam & Saffron

A saffron and cream food editorial variant with large steam contours and a less literal offer hierarchy. Use when the team wants a slightly more premium, appetite-led handout.

### 04 — Afterglow

A charcoal and hot-orange poster designed for strong contrast in late-afternoon foot traffic. Use when the team wants a bolder, Shark Tank nod without relying on a literal screen-grab or excessive logos.

### 05 — Crossroads

A calmer collector’s cut that brings Jaipur jharokha rhythm into conversation with Kyoto-inspired lattice restraint. It preserves the same real Mami Momos menu anchors, flyer offer, and Gangori Bazaar location, while offering an editorial alternative to the high-heat poster variations.

## Export Requirements

The frontend studio should allow the user to select a design, preview it at its exact A5 proportion, and trigger the following actions:

| Action | Expected result |
| --- | --- |
| Export PDF | Downloads a print-ready A5 PDF with bleed/safe-area guide options; printer can receive this file directly |
| Export SVG | Downloads a Figma-importable vector-oriented flyer file |
| Export PNG | Downloads a high-resolution preview image suitable for review and quick sharing |
| Print Preview | Opens the browser print dialog with A5-focused print CSS |
| Copy Spec | Copies the selected design’s production notes to the clipboard |

## Print Notes

Ask the printer for uncoated or matte 170–220 GSM stock to retain legibility under heavy daylight and avoid glare. Proof one sample in sunlight before a full run. Use CMYK conversion at the final print-stage if the printer requires it; the studio remains in sRGB for browser display.
