# Shared brochure reference notes

- `/home/ubuntu/projects/mami-momos-d4d38916/6 Pages_A4 Menu Jaipur.pdf`

## Key visual findings

- The brochure is a **6-page A4 portrait menu** with a calm cream background and layered teal watercolour mountain landscape.
- Typography is high-contrast, serif-led, and feels closer to an editorial poster than a standard restaurant flyer.
- Page 1 functions as a **cover page**, featuring the heading `MENU` and three brand marks: **Yangkiez by Momo Mami**, **Jagri Tea**, and **Zen'China**.
- Pages 2–5 are interior menu pages with food categories and prices arranged in a vertically flowing single-page catalogue.
- The visual language is soft, misty, and painterly rather than photo-heavy, so the dashboard should present these pieces like curated print sheets.

## Design implications for the dashboard

- The real brochure already offers a strong identity, so the dashboard should preserve a **print-archive viewing feel** instead of turning it into a generic corporate gallery.
- For the Mami Momos tile, one variant can use the **cover as front** and an interior page as **back** for a meaningful front/back toggle.
- Additional variants can be represented as different interior spreads or alternate preview sets while keeping instant preview updates.
